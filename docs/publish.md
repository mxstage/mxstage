# 公開する（GitHub へ送る）

mxstudio は客先の Maximo を相手に作ってきたので、気を付けないと客先の情報（社名・サイト・客先独自の構造や属性の名前・
接続先・番号の形式など）がリポジトリに入ります。**送る前に必ず検査し、当たれば送りません。**

## 履歴について

最初のコミットには客先の情報が入っていたため、2026-09-27 に、その時点の中身だけで最初のコミットを作り直しました。
古い履歴は、この PC のローカルのブランチ `private/before-publish-2026-09-27` にだけ残しています。
**このブランチは送りません**（送ろうとすると、下の検査が止めます）。要らなくなったら消してかまいません。

## 客先の語の一覧（リポジトリの外）

検査は `~/.config/mxstudio/publish-terms.txt` にある語を探します。**一覧そのものが客先の情報なので、リポジトリには入れません。**
一覧が無いときは、確かめようがないので送りません。

- 1 行に 1 つ。JavaScript の正規表現で書きます（例 `\bEXT_[A-Z]+\b`）。先頭に `i:` を付けると大文字小文字を区別しません。
- `#` で始まる行と空行は読み飛ばします。
- 社名・サイトのコード・客先独自の構造や属性の名前・接続先のホスト名・番号の形式に加えて、
  **人名や協力会社名、実データの文言など、思い当たるものを足してください。** 検査は一覧にある語しか見つけません。
- 別の場所に置くときは、環境変数 `MXSTUDIO_PUBLISH_TERMS` にパスを入れます。

## 検査

**自動（プッシュのたび）**: `.githooks/pre-push` が `scripts/check-publish.mjs` を動かし、送ろうとしているコミット
（送り先にまだ無いもの）をすべて調べます。調べるのは、各コミットのファイルの中身（テキストだけ）・ファイルのパス・コミットの説明文です。
リポジトリを取得したら、最初に 1 回だけ有効にします。

```bash
git config core.hooksPath .githooks
```

**手で**: 送る前やコミットの前に確かめるとき。

```bash
node scripts/check-publish.mjs              # 今のブランチの履歴
node scripts/check-publish.mjs --worktree   # 履歴と、まだコミットしていない変更
node scripts/check-publish.mjs --all        # すべてのブランチとタグ
```

終了コードは 0 = 当たりなし、1 = 当たりあり、2 = 語の一覧が無いなどで調べられない、です。

## 当たったら

- **まだコミットしていない変更**: 当たったところを消すか、架空の名前に置き換えます（試験のデータは `BEDFORD`・`A5001` のような架空の値にそろえています）。
- **コミットに入ってしまった**: 送る前なら、そのコミットを直してから送ります。古いコミットに残っているときは、そのコミットを送らないよう履歴を作り直します。
  今の中身が検査を通ることを確かめてから、今の中身だけで最初のコミットを作り直す例です（古い履歴はローカルのブランチに残します）。

```bash
git branch private/before-publish-<日付> main
git update-ref refs/heads/main $(git commit-tree HEAD^{tree} -m "公開用の最初のコミット") HEAD
```

## 送る

- 送り先を足します（公開か非公開かは、送り先のリポジトリを作るときに決めます）: `git remote add origin <URL>`
- **`main` だけを送ります**: `git push -u origin main`。`--all` や `--mirror` は使いません（ローカルだけのブランチまで送ろうとします）。
- `--no-verify` で検査を飛ばさないでください。
